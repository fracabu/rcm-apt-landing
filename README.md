<a name="english"></a>
## :gb: English

### Overview

A modern and responsive single-page application designed to manage and promote direct bookings for a luxury tourist apartment in Rome.

### Features

- **Direct Booking** - No OTA commissions
- **Photo Gallery** - Property showcase
- **Availability Calendar** - Check dates
- **Contact Form** - Inquiry submission
- **Responsive Design** - Mobile-friendly

### Quick Start

```bash
git clone https://github.com/fracabu/rcm-apt-landing.git
cd rcm-apt-landing
npm install
npm run dev
```
